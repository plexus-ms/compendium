This section holds the essential documentation about Plexus itself:

- [**The Plexus Manifesto**](manifesto.md) — Answers the high-level why. Readers unfamiliar with Plexus are recommended to start here.
- [**The Plexus Standard (PLX)**](standard.md) — The Plexus specification entrypoint. PLX is organized as a map of different modules, each of which has a specific concern and can be adopted individually. For the modules themselves, see the [PLX Modules](../modules/index.md) section.
- [**Reference stack**](reference-stack.md) — A specific description of the tech stack and module composition that we, the maintainers, run in our own production workloads. This is what each Plexus release is built with and tested against. Other stacks are possible, of course, but this is the one that has been exercised and proven to work.
