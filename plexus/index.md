This section holds fundamental documentation about Plexus itself:

- [**The Plexus Manifesto**](manifesto.md) — Answers the high-level why. Readers unfamiliar with Plexus are recommended to start here.
- [**The Plexus Standard (PLX)**](standard.md) — The Plexus specification entrypoint. PLX is organized as a map of different modules, each of which has a specific concern and can be adopted individually. For the modules themselves, see the [PLX Contracts](../contracts/index.md) and [PLX Approaches](../approaches/index.md) sections.
